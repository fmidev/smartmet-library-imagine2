# smartmet-library-imagine2

Part of [SmartMet Server](https://github.com/fmidev/smartmet-library-spine). See the [SmartMet Server documentation](https://github.com/fmidev/smartmet-library-spine) for an overview of the ecosystem.

## Overview

The imagine2 library is the updated 2D graphics rendering library for SmartMet Server, succeeding [smartmet-library-imagine](https://github.com/fmidev/smartmet-library-imagine). It provides drawing primitives and image manipulation for weather map product generation.

## Features

- 2D graphics rendering and image compositing
- Bezier curve support
- Color blending and image transformation
- Raster image output

## Usage

Used by SmartMet Server rendering tools for weather map product generation.
